QH Uploader Privacy Policy

Last updated: October 21, 2026

QH Uploader is a personal tool operated by Akachi Maduako. It is used only by its owner to upload and schedule original music videos to the owner's own YouTube channel, Quiet Hours Music. It is not offered to the public.

Data accessed

The tool requests the YouTube upload permission (youtube.upload) for the owner's own Google account. It uses this permission only to upload videos, thumbnails and playlist entries that the owner created.

Data stored and shared

The tool does not collect data from any other person. The owner's authorization token is stored only on the owner's own computer. No data is sold, shared with third parties, or transferred to any server operated by the developer.

YouTube API Services

The tool uses YouTube API Services. Use of the tool is subject to the YouTube Terms of Service and the Google Privacy Policy. The owner can revoke the tool's access at any time at security.google.com/settings/security/permissions.
