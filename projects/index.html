Banking Pentest · Local training target

DVBank Security Audit

Completed a bounded audit of a local DVBank training application. Four runtime checks covered an unauthenticated profile route (404), transaction receipt route (200), admin listing (401), and headers/CORS behavior on an authenticated endpoint (401). The report records 19 findings: three runtime observations and 16 source-review observations.

The review noted an unauthenticated receipt response with status 200, missing browser security headers, credentialed CORS reflecting a test origin, disabled JWT signature verification in source, MD5 calls, dynamic execution and possible SQL interpolation. The receipt body was not preserved, so the audit does not claim what data it exposed; source findings require manual validation.

Scope: local training application, read-only HTTP checks and source review. No brute force, transfer submission, upload, command execution or race testing.

Manufacturing OT · Suricata + Zeek

GridWatch Modbus Detection

Ran GridWatch’s generated 169-packet capture through Suricata and Zeek. Suricata reported 122 alert events attributed to the simulated attacker host 127.0.0.2. Alert categories included unauthorized Modbus writes (44), coil writes (43), write-flood behavior (28), read sweeps (5), diagnostics requests (1) and holding-register writes (1).

Demonstrates: safe PCAP-based OT monitoring, signature review, source attribution and structured event output. The traffic was generated for the lab and did not come from a live control system.

Manufacturing OT · CISA CTEP

Critical Manufacturing Ransomware Tabletop

Built a discussion-based exercise for fictional Northstar Components from CISA’s Critical Manufacturing CTEP materials. The scenario progresses from threat activity and vendor access to a malicious vendor-themed email, data exfiltration, altered or missing shared files, and encrypted PLC data.

Participants consider incident command, plant safety, vendor coordination, backup recovery, PLC integrity checks, manual operations and external notifications. GridWatch’s synthetic Modbus evidence supports discussion of detection and containment. No live plant, PLC or production network was tested.
